# Live Demo Scenario

## 1. Opening

Show the login page and explain that this is a role-based project monitoring dashboard for portfolio demonstration.

## 2. Project Manager View

Login as Project Manager and show:

- Command Center overview,
- project KPI cards,
- project list,
- schedule overview,
- notifications,
- project detail.

## 3. Project Detail

Open one active project and show:

- project summary,
- task tracker,
- timeline,
- document readiness,
- project updates,
- report center.

## 4. Schedule

Show online and onsite agenda labels, schedule detail, and internal agenda behavior.

## 5. Project Management

Show project lifecycle, client access, branding, and access control.

## 6. Client Portal

Login as a Client account and show that only Beranda, Project, and Schedule are available.

Confirm that the client cannot access:

- Activity Log,
- Backup Data,
- Project Management,
- internal agenda,
- other projects.

## 7. Closing

Close with the technical architecture:

- Vanilla JavaScript frontend,
- Supabase backend,
- PostgreSQL database,
- Supabase Auth and RLS,
- Vercel hosting,
- GitHub version control.
