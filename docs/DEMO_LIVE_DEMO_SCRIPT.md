# Live Demo Script — Professional Project Dashboard

## Recommended Duration
3–5 minutes.

## Opening

This is a Professional Project Dashboard built as a portfolio-ready project governance platform. The dashboard is designed to centralize project visibility, schedule tracking, task monitoring, documentation, and structured report downloads in one role-based workspace.

The demo uses sample project data across several industries, so the walkthrough can show both completed and active project scenarios without exposing real client information.

## Step 1 — Login and Role Context

Start by explaining that the dashboard supports multiple user roles, including PM, Admin, and Client access. Each role is designed to provide the right level of visibility based on stakeholder responsibility.

For the main walkthrough, use the PM account because it shows the complete project governance view.

## Step 2 — Home Dashboard

On the home dashboard, highlight the portfolio overview. Explain the total number of projects, active projects, completed projects, today’s schedule, and project agenda.

Emphasize that this page gives management and delivery teams a quick view of overall project health and current operational activity.

## Step 3 — Project Detail

Open one active project and explain that the project detail page consolidates the key delivery information.

Highlight:

- Timeline Summary
- Task Monitoring
- Project Timeline
- Document List
- Document Output
- Schedule
- Meeting and update log

Explain that this structure helps reduce fragmented reporting because project status, progress, and documentation can be reviewed in one place.

## Step 4 — Schedule

Open the schedule section and show the Online and Onsite distinction.

Explain that the schedule view helps stakeholders understand which activities are remote and which require physical presence. This is useful for project planning, audit activities, workshops, and client coordination.

## Step 5 — Report Download

Show the report download options:

- Executive Summary
- Complete Report
- Project Timeline

Explain that the report export feature supports faster management reporting and creates a consistent reporting format for project stakeholders.

## Step 6 — Client View

If time allows, switch to a client account and explain that the client view is intentionally more focused. The client can see relevant project information without accessing internal-only operational areas.

## Closing

The main value of this dashboard is visibility. It helps project teams manage project information, communicate status clearly, and provide stakeholders with structured reports from a single platform.
