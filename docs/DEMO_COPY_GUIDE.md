# Professional Project Dashboard — Copy Guide

## Purpose

This guide keeps the Professional Project Dashboard demo consistent, business-ready, and suitable for portfolio presentation.

---

## Language Rules

### Indonesian Mode

Use Indonesian consistently across labels, actions, messages, and report titles.

Examples:

- `Total Proyek`
- `Proyek Aktif`
- `Proyek Selesai`
- `Rata-rata Progres`
- `Jadwal Hari Ini`
- `Agenda Proyek`
- `Ringkasan Linimasa`
- `Pemantauan Tugas`
- `Linimasa Proyek`
- `Unduh Laporan`

### English Mode

Use English consistently across labels, actions, messages, and report titles.

Examples:

- `Total Projects`
- `Active Projects`
- `Completed Projects`
- `Average Progress`
- `Today’s Schedule`
- `Project Agenda`
- `Timeline Summary`
- `Task Monitoring`
- `Project Timeline`
- `Download Report`

## Message Standards

### Indonesian

- `Perubahan berhasil disimpan.`
- `Perubahan agenda berhasil disimpan.`
- `Laporan berhasil diunduh.`
- `Laporan belum dapat diunduh. Silakan coba kembali.`
- `Belum ada data yang tersedia.`
- `Data ini hanya tersedia untuk pengguna dengan akses terkait.`

### English

- `Changes have been saved successfully.`
- `Agenda changes have been saved successfully.`
- `The report has been downloaded successfully.`
- `The report could not be downloaded. Please try again.`
- `No data is currently available.`
- `This data is only available to users with the required access.`

---

## Demo Data Terms

Use these terms:

- `Demo Data`
- `Sample Data`
- `Sample Project Data`
- `Demo Portfolio Data`

Avoid these terms in user-facing copy:

- `Dummy`
- `Dummy Data`
- `Fake Data`
- `Testing Only`

---

## Documentation Tone

Developer documentation may mention technical terms such as `fallback`, `SVG`, `pdfMake`, or `getBlob()`.

User-facing documentation should explain the outcome, not the internal implementation.

Example:

- Avoid: `SVG image fallback fixed for pdfMake.`
- Use: `Reports now download reliably using compatible brand assets.`
