# SOP — Project Onboarding

SOP ini digunakan Project Manager saat membuat project baru di Professional Project Dashboard.

## 1. Tujuan

Memastikan project baru dibuat dengan data awal yang rapi, akses client aman, dan siap dipantau melalui dashboard.

## 2. Prasyarat

Sebelum membuat project, siapkan:

```text
Nama project
Nama client
Project owner / PM
Tanggal mulai
Target selesai
Scope utama
Milestone awal
Kebutuhan client access
Logo/branding client jika ada
```

## 3. Membuat Project Baru

Langkah:

```text
1. Login sebagai Project Manager.
2. Buka Kelola Project.
3. Pilih tambah project baru.
4. Isi nama project dan informasi dasar.
5. Simpan project.
6. Pastikan project muncul pada Project Berjalan.
```

## 4. Menyiapkan Timeline dan Task

Setelah project dibuat:

```text
1. Buka detail project.
2. Isi timeline project.
3. Sinkronkan task tracker dari timeline.
4. Lengkapi PIC, due date, status, dan progress.
5. Pastikan task penting tidak kosong.
```

## 5. Menyiapkan Dokumen

Lengkapi daftar dokumen project:

```text
Document List
Document Output
Status dokumen
Owner dokumen
Due date jika tersedia
```

## 6. Menyiapkan Schedule

Buat agenda awal project:

```text
Kick-off Meeting
Project Sync
Discussion
Presentation
Audit
Technical Onsite
```

Tentukan mode:

```text
Online
Onsite
```

Gunakan checklist Internal agenda jika agenda tidak boleh ditampilkan kepada client.

## 7. Menyiapkan Branding

Di Kelola Project, lengkapi branding:

```text
Prepared For
Prepared By
Confidentiality Label
Footer
Client Logo
Accent Color
```

Bahasa report tidak diatur di branding karena sudah dipilih saat export.

## 8. Menyiapkan Client Access

Jika client perlu akses dashboard, lanjutkan ke SOP Client Access.

## 9. Checklist Final Onboarding

```text
Project sudah dibuat.
Timeline awal sudah tersedia.
Task tracker sudah terisi.
Dokumen utama sudah masuk.
Schedule awal sudah dibuat.
Branding sudah sesuai.
Client access sudah dibuat jika diperlukan.
Report export sudah dites.
```
