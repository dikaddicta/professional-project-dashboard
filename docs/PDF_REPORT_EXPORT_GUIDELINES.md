# PDF Report Export Guidelines

The PDF export feature is designed to provide clear project reporting for internal and stakeholder communication.

## Report Types

- Executive Summary
- Full Report Pack
- Project Timeline

## Language Options

Each export can be generated in:

- Bahasa Indonesia
- English

The selected language should apply consistently to titles, labels, descriptions, table headers, and report notes.

## Client Report Rules

Client report output should only include information that is appropriate for stakeholder communication. Internal agenda, internal notes, activity logs, and backup records must remain excluded from client exports.

## Recommended Writing Style

Use concise and professional wording. Avoid system-style language and raw operational notes when a business summary is more appropriate.

Preferred style:

- Clear project status
- Specific progress information
- Practical follow-up actions
- Consistent terminology
- Natural business language

Avoid:

- Raw internal notes
- Unedited meeting comments
- Technical implementation terms
- Mixed language in a single report unless required by project context
- Long paragraphs without structure

## Visual Standard

The report should maintain:

- Clean cover section
- Consistent page margins
- Clear section hierarchy
- Balanced tables
- Readable font sizing
- Stable footer and page number
- Consistent color usage

## Final Review

Before sharing a report externally, check:

1. Correct project name and client name.
2. Correct report language.
3. No internal agenda is included for client users.
4. Latest update is written in a professional tone.
5. Tables are not cut off unexpectedly.
6. Footer and confidentiality label are consistent.
