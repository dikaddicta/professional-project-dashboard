# SOP — Report Export

SOP ini digunakan untuk mengunduh report project dari Professional Project Dashboard.

## 1. Jenis Report

Report yang tersedia:

```text
Ringkasan Eksekutif
Paket Laporan Lengkap
Timeline Project
```

## 2. Pilihan Bahasa

Sebelum export, pilih bahasa:

```text
Bahasa Indonesia
English
```

Pilihan bahasa berlaku untuk report yang diunduh saat itu.

## 3. Export Ringkasan Eksekutif

Gunakan report ini untuk management-level summary.

Berisi ringkasan:

```text
Status project
Progress
Current phase
Next milestone
Highlight update
Attention point
Agenda terdekat
```

## 4. Export Paket Laporan Lengkap

Gunakan report ini untuk dokumentasi progress project yang lebih detail.

Berisi:

```text
Executive Summary
Project Progress
Document Status
Risk & Issue Summary
Client Handover Readiness
Agenda Project Terdekat
```

## 5. Export Timeline Project

Gunakan report ini untuk melihat timeline dan milestone project.

## 6. Checklist Sebelum Report Dibagikan

```text
Data project sudah terbaru.
Timeline sudah sesuai.
Task tracker sudah diperbarui.
Document status sudah benar.
Schedule sudah dicek.
Bahasa report sudah sesuai.
Logo/branding sudah benar.
Report client tidak memuat data internal.
```

## 7. Catatan Role

```text
PM/Admin dapat mengunduh report sesuai akses internal.
Client/Guest hanya mengunduh report dengan data yang aman ditampilkan.
```
