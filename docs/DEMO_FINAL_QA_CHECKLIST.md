# Final QA Checklist — Professional Project Dashboard

## Access

- [ ] PM account can login.
- [ ] Admin account can login.
- [ ] Client account can login.
- [ ] Client only sees relevant project access.
- [ ] No blank page appears after login.

## Home Dashboard

- [ ] Total projects are displayed correctly.
- [ ] Active projects are displayed correctly.
- [ ] Completed projects are displayed correctly.
- [ ] Today’s schedule appears correctly.
- [ ] Project agenda appears correctly.
- [ ] Language is consistent and professional.

## Project Detail

- [ ] Timeline Summary displays correctly.
- [ ] Task Monitoring displays correctly.
- [ ] Project Timeline displays correctly.
- [ ] Document List displays correctly.
- [ ] Document Output displays correctly.
- [ ] Meeting/update log displays correctly.

## Schedule

- [ ] Online schedule uses sage tone.
- [ ] Onsite schedule uses bronze tone.
- [ ] Legend is clear.
- [ ] Edit Agenda opens correctly.
- [ ] Agenda update can be saved.
- [ ] Schedule remains readable on mobile.

## PDF / Report Download

- [ ] Executive Summary can be downloaded.
- [ ] Complete Report can be downloaded.
- [ ] Project Timeline can be downloaded.
- [ ] PDF export does not trigger image format errors.
- [ ] Report layout is readable and professional.

## Visual Consistency

- [ ] No remaining blue CY-WA visual tone appears in user-facing components.
- [ ] Cards, badges, chips, and buttons follow the white/sage/bronze/charcoal theme.
- [ ] Layout is screenshot-ready on desktop.
- [ ] Layout is usable on mobile Chrome.

## Portfolio Readiness

- [ ] Screenshots have been captured based on the shot list.
- [ ] Live demo can be completed in 3–5 minutes.
- [ ] Portfolio case study is ready to copy into GitHub README or personal website.
- [ ] GitHub repository is clean.
