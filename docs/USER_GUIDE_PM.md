# User Guide — Project Manager

Panduan ini menjelaskan cara menggunakan Professional Project Dashboard sebagai Project Manager.

## 1. Akses Menu

Project Manager melihat menu:

```text
Beranda
Notifikasi
Activity Log
Backup Data
Project
Schedule
Kelola Project
```

## 2. Beranda

Gunakan Beranda untuk melihat ringkasan project, notifikasi, agenda, dan status progress secara cepat.

Hal yang perlu dicek setiap hari:

```text
Notifikasi prioritas
Schedule hari ini
Agenda project terdekat
Project dengan progress tinggi yang perlu ditandai selesai
Task overdue atau blocked
```

## 3. Mengelola Project

Buka **Kelola Project** untuk:

```text
Membuat project baru
Mengatur status project
Mengarsipkan atau memulihkan project
Mengatur client access
Mengatur branding project
```

Status project:

```text
Berjalan : project masih aktif.
Selesai  : project selesai secara bisnis dan tetap bisa dilihat/report.
Arsip    : project disembunyikan dari tampilan aktif.
```

## 4. Mengelola Client Access

Gunakan Client Access untuk membuat atau mengatur akun client/guest pada project tertentu.

Prinsip penggunaan:

```text
Berikan akses hanya untuk project yang relevan.
Nonaktifkan akses jika project selesai atau akses tidak lagi diperlukan.
Reset password jika client kehilangan akses.
```

## 5. Mengelola Schedule

Buka **Schedule** untuk membuat agenda project.

Field penting:

```text
Project
Judul agenda
Tipe agenda
Mode Online/Onsite
Tanggal
Start time
End time
Location / Link
Internal agenda
Description
```

Gunakan **Internal agenda** untuk agenda yang hanya boleh dilihat PM/Admin. Agenda internal tidak tampil untuk Client/Guest.

## 6. Export Report

Pada Report Center, pilih bahasa:

```text
Bahasa Indonesia
English
```

Jenis report:

```text
Ringkasan Eksekutif
Paket Laporan Lengkap
Linimasa Proyek
```

Sebelum membagikan report ke client, pastikan:

```text
Data project sudah terbaru.
Agenda internal tidak masuk report client.
Logo dan branding sudah sesuai.
Bahasa report sudah benar.
```

## 7. Activity Log

Activity Log digunakan untuk meninjau perubahan penting pada dashboard.

Gunakan filter untuk mencari aktivitas berdasarkan project, module, action, atau keyword.

## 8. Backup Data

Backup Data digunakan untuk export data project secara read-only.

Format yang tersedia:

```text
JSON backup project
JSON backup semua project
CSV Pemantauan Tugas
CSV Schedule
CSV Activity Log
```

File backup harus disimpan di lokasi internal yang aman.

## 9. Rekomendasi Operasional Harian

```text
1. Cek Beranda dan Notifikasi.
2. Cek agenda hari ini di Schedule.
3. Update task dan timeline jika ada perubahan.
4. Tambahkan client update jika ada progress penting.
5. Export report jika diperlukan.
6. Review Activity Log untuk perubahan penting.
```
