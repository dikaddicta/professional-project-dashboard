# User Guide — Admin

Panduan ini menjelaskan cara menggunakan Professional Project Dashboard sebagai Admin.

## 1. Akses Menu

Admin melihat menu:

```text
Beranda
Notifikasi
Project
Schedule
Kelola Project
```

Admin tidak melihat:

```text
Activity Log
Backup Data
```

## 2. Beranda

Gunakan Beranda untuk memantau ringkasan project, progress, dan agenda. Data yang tampil digunakan untuk monitoring dan koordinasi operasional.

## 3. Project

Pada menu Project, Admin dapat membuka detail project dan memantau:

```text
Progress project
Timeline
Task Tracker
Dokumen
Update project
Risk dan issue
Report Center
```

## 4. Schedule

Admin dapat melihat agenda project. Jika konfigurasi aplikasi mengizinkan, Admin dapat membantu monitoring schedule. Namun perubahan yang bersifat governance tetap menjadi tanggung jawab Project Manager.

## 5. Kelola Project

Admin dapat membantu melihat atau mengelola data project sesuai akses yang diberikan aplikasi. Untuk perubahan penting seperti status selesai, arsip, client access, atau branding, lakukan koordinasi dengan Project Manager.

## 6. Batasan Admin

Admin tidak memiliki akses ke:

```text
Activity Log
Backup Data
Export Activity Log
Data backup internal
```

Batasan ini dibuat agar fitur governance tetap berada di Project Manager.

## 7. Rekomendasi Operasional

```text
1. Cek Beranda untuk ringkasan project.
2. Cek Notifikasi untuk prioritas.
3. Review Schedule sebelum meeting atau project sync.
4. Bantu PM memastikan data project tetap rapi.
5. Laporkan anomali akses atau data kepada PM.
```
