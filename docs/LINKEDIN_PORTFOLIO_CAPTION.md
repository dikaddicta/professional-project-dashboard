# LinkedIn Portfolio Caption

I recently developed a portfolio-ready web dashboard called Professional Project Dashboard.

This project demonstrates how project delivery information can be structured into one dashboard for PM, Admin, and Client users. It includes project portfolio monitoring, schedule visibility, task monitoring, project timeline tracking, and executive report downloads using sample project data.

The main focus was not only building the interface, but also shaping a business-ready product experience: clean role-based visibility, professional reporting flow, responsive layout, and consistent UI copy.

Tech stack:
HTML, CSS, Vanilla JavaScript, Supabase, PostgreSQL, Supabase Auth, Row Level Security, Supabase Edge Functions, Vercel, and GitHub.

Key areas demonstrated:
- Project governance dashboard design
- Multi-role access flow
- Schedule and task monitoring
- Project timeline visualization
- Executive report export
- Business-oriented UI/UX polish

This project helped me strengthen the connection between project management thinking and technical product execution.
