# Professional Project Dashboard

Professional Project Dashboard is a portfolio-ready project governance dashboard designed to demonstrate multi-role project monitoring, schedule management, task tracking, timeline visualization, and executive report generation.

The application uses sample project data to simulate a professional delivery environment across PM, Admin, and Client views.

## Overview

This project was developed as a web-based project management and governance dashboard. It is designed to present project status, delivery progress, schedule visibility, document tracking, and executive reporting in a clean business interface.

The demo environment contains sample projects across technology, compliance, security, migration, and operational transformation scenarios.

## Key Capabilities

- Multi-role dashboard experience for PM, Admin, and Client users.
- Project portfolio overview with active and completed project visibility.
- Project detail page with progress, timeline, document, task, and update tracking.
- Schedule management with Online and Onsite classification.
- Task monitoring and project timeline visualization.
- Executive Summary, Complete Report, and Project Timeline report downloads.
- Responsive layout for desktop and mobile review.
- Business-focused UI copy with professional Indonesian terminology.

## Product Focus

The dashboard is structured to support project governance activities such as:

- Monitoring delivery progress across multiple projects.
- Reviewing agenda, meetings, onsite sessions, and online discussions.
- Tracking project tasks and milestone movement.
- Presenting executive-level reports in a concise format.
- Separating internal and client-facing project visibility.

## User Roles

| Role | Purpose |
|---|---|
| PM | Oversees portfolio delivery, project status, schedule, tasks, timeline, and reports. |
| Admin | Supports project data management and operational monitoring. |
| Client | Reviews assigned project information, schedule, timeline, and available reports. |
