# User Guide — Client / Guest

Panduan ini menjelaskan cara menggunakan Professional Project Dashboard sebagai Client/Guest.

## 1. Akses Menu

Client/Guest melihat menu:

```text
Beranda
Project
Schedule
```

Client/Guest hanya melihat project yang diberikan akses.

## 2. Beranda

Beranda menampilkan ringkasan project, dokumen, progress, update, dan agenda yang tersedia untuk akun Anda.

Informasi yang dapat dipantau:

```text
Status Project
Progress Project
Kesiapan Dokumen
Jadwal Hari Ini
Agenda Terdekat
Update Terbaru
```

## 3. Project

Menu Project menampilkan detail project yang dapat Anda akses.

Informasi yang tersedia:

```text
Overview project
Timeline
Task progress
Document status
Project update
Report Center
```

## 4. Schedule

Schedule menampilkan agenda project yang dapat Anda pantau.

Catatan:

```text
Schedule bersifat read-only.
Client/Guest tidak dapat menambah, mengedit, atau menghapus agenda.
Agenda internal tidak ditampilkan.
```

## 5. Export Report

Pada Report Center, Anda dapat memilih bahasa report:

```text
Bahasa Indonesia
English
```

Jenis report:

```text
Ringkasan Eksekutif
Paket Laporan Lengkap
Linimasa Proyek
```

## 6. Batasan Akses

Client/Guest tidak melihat:

```text
Activity Log
Backup Data
Kelola Project
Internal agenda
Internal note
Data project lain
```

## 7. Rekomendasi Penggunaan

```text
1. Buka Beranda untuk melihat ringkasan terbaru.
2. Buka Schedule untuk melihat agenda project.
3. Buka Project untuk melihat detail progress dan dokumen.
4. Gunakan Report Center untuk mengunduh report sesuai kebutuhan.
```
